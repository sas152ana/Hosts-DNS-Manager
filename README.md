# Hosts & DNS Manager

**Hosts & DNS Manager** — это утилита для операционной системы Windows, предназначенная для управления системным файлом `hosts` и выборочной маршрутизации трафика конкретных веб-сервисов. 

Программа позволяет связывать домены выбранных сайтов и платформ с IP-адресами различных специализированных DNS-серверов. Это дает возможность направлять трафик отдельных ресурсов через альтернативные узлы (например, для обхода ограничений или оптимизации пинга), не изменяя настройки DNS для всей системы.

## Основные возможности

* **Выборочная настройка сервисов**: Возможность задавать индивидуальный режим работы или конкретный DNS-провайдер отдельно для каждого сайта или платформы (Discord, YouTube, ChatGPT, Spotify и др.).
* **Разнообразие профилей DNS**: Поддержка популярных и специализированных DNS-сервисов, включая:
  * Xbox DNS / Xbox DNS (old)
  * Comss DNS
  * Malw DNS / Malw DNS v2
  * play2go.cloud DNS
  * Zapret DNS
  * Fin DNS
  * Ручной режим (`Вкл. (ручной hosts)`)
* **Группировка и массовое управление**: Сервисы распределены по категориям («Напрямую из hosts», «ИИ», «Остальные»), для каждой из которых доступно быстрое включение или выключение всех элементов группы.
* **Безопасность и восстановление**: 
  * Автоматическое или ручное создание резервных копий файла `hosts`.
  * Функция восстановления из бэкапа в один клик.
  * Очистка созданных программой блоков записей без повреждения сторонних строк в `hosts`.
* **Удобный интерфейс**:
  * Встроенный поиск по списку сервисов.
  * Мониторинг статуса (количество активных доменов, распознанных сервисов и доступность файла для записи).
  * Поддержка светлой и темной тем оформления.

## Как это работает

При выборе определенного DNS-сервера для ресурса утилита обращается к этому DNS, получает актуальные IP-адреса для доменов сервиса и записывает полученные сопоставления «IP — Домен» прямо в файл `hosts` (обычно расположенный по пути `C:\Windows\System32\drivers\etc\hosts`). В результате операционная система обращается к выбранным сайтам по адресам, предоставленным указанным DNS-сервером, минуя стандартный системный DNS-резолвер.

## Инструкция по использованию

1. **Запуск**: Запустите исполняемый файл программы. 
   > *Примечание: Для работы программы требуются права администратора, так как редактирование файла `hosts` является системной операцией.*
2. **Выбор конфигурации**:
   * Найдите интересующий вас сервис в списке (или используйте строку поиска в левом верхнем углу).
   * В выпадающем меню напротив сервиса выберите нужный вариант DNS (например, `Fin DNS` или `Zapret DNS`).
3. **Применение изменений**: Нажмите кнопку **«Применить в hosts»** в правом нижнем углу интерфейса.
4. **Управление файлом**:
   * Чтобы открыть текущий файл `hosts` во встроенном текстовом редакторе, нажмите **«Открыть hosts»**.
   * Для удаления внесенных программой изменений нажмите **«Очистить блок»**.
   * При возникновении неполадок воспользуйтесь кнопкой **«Восстановить бэкап»**.
