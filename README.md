# 🌐 Hosts & DNS Manager

**Hosts & DNS Manager** — мощное и удобное графическое приложение (PyQt5 для Windows), предназначенное для гибкого управления файлом `hosts`, сетевыми DNS-адаптерами и точечного обхода гео-блокировок зарубежных сервисов и нейросетей (**ChatGPT, Claude, Google AI Studio / Gemini, Notion, Spotify, Canva** и др.) по технологии **SmartDNS / SNI-Proxy** без необходимости включать классический VPN.

---

## 💡 Как это работает (SmartDNS + hosts vs VPN)

В отличие от тяжелых VPN-клиентов, которые перенаправляют весь интернет-трафик вашего компьютера через зарубежный канал:
1. **Точечная маршрутизация**: В системный файл `hosts` прописываются только IP-адреса зарубежных шлюзов (SNI-прокси) для конкретных заблокированных сайтов.
2. **Максимальная скорость**: Весь ваш остальной трафик (российские сайты, банки, онлайн-игры, торренты, YouTube) идет напрямую на максимальной скорости вашего провайдера.
3. **Работа без статических DNS на сетевой карте**: У большинства современных SmartDNS нет публичных IP-адресов для сетевой карты. Наше приложение самостоятельно отправляет защищенные DoH-запросы к серверам, выясняет актуальные IP-шлюзы и автоматически заносит их в `hosts`.

## 🖥️ Подробный обзор вкладок и элементов управления

### 1. Вкладка «Сайты (hosts)»
Основное рабочее пространство для включения и настройки нужных сервисов.

* **Поиск сервиса** — мгновенная фильтрация сервисов по названию в реальном времени.
* **Выпадающий список «Всем:»** — позволяет в один клик выбрать вариант DNS сразу для всех сервисов в каталоге.
* **Кнопка «Вкл. все» / «Выкл. все»** — массовое включение или выключение всех доступных сервисов.
* **Кнопка «+ Добавить сайт»** — открывает диалог добавления собственного сайта или сервиса:
  * Ввод названия (пользовательские сайты помечаются звездочкой `★`).
  * Выбор категории из существующих или ввод названия новой группы.
  * Режим работы (*SmartDNS* или *Прямой hosts*).
  * Ввод любого количества доменов (по одному на строку).
  * Возможность сразу указать стартовые IP (необязательно).
* **Кнопка «+ Категория»** — быстрое создание новой пользовательской группы сайтов.
* **Кнопка «Считать из hosts»** — умный анализатор: сканирует ваш текущий файл `hosts` и автоматически выставляет переключатели в приложении в соответствии с тем, какие сервисы и варианты DNS уже фактически включены в системе.
* **Групповые заголовки категорий**:
  * Содержат выпадающий список **«Всей группе:»** для массового переключения варианта DNS только внутри конкретной категории.
  * **Правый клик по заголовку группы** — позволяет переименовать категорию сразу для всех входящих в нее сайтов.
* **Список сервисов (Сетка)**:
  * **Чекбокс `✓`** — быстрое включение/отключение сервиса. При установке галочки автоматически выбирается первый доступный вариант DNS; при снятии — вариант переходит в «— выкл —».
  * **Цветовой индикатор** — визуальная метка сервиса.
  * **Выпадающий список «Вариант DNS»** — выбор шлюза, через который будет открываться конкретно этот сервис.
  * **Двойной клик по названию сайта** — открывает детальный редактор доменов и IP-адресов.
  * **Правый клик по названию сайта (Контекстное меню)**:
    * ✏️ **Редактировать сервис / домены…** — изменение названия, категории, списка доменов и адресов.
    * 📁 **Переместить в категорию ▾** — мгновенный перенос сайта в любую существующую группу или создание новой.
    * 🗑️ **Удалить сервис** — удаляет пользовательский сайт из базы и настроек. *Встроенные системные сервисы защищены от удаления во избежание повреждения базы данных.*
* **Нижняя панель управления**:
  * **Статусная строка** — отображает количество активных записей в `hosts`, число распознанных сервисов и права доступа (чтение/запись).
  * **«Открыть hosts»** — открывает системный файл `hosts` в Блокноте от имени Администратора.
  * **«Восстановить бэкап»** — выбор и откат к любой из автоматически созданных резервных копий.
  * **«Очистить блок»** — удаляет блок записей программы из `hosts`, возвращая файл к исходному состоянию.
  * **«Применить в hosts»** — производит безопасную запись выбранных конфигураций в файл `hosts` (создавая бэкап) и автоматически сбрасывает системный DNS-кэш Windows (`ipconfig /flushdns`).

### 2. Вкладка «DNS-серверы»
Управление DNS-серверами на физических и беспроводных сетевых картах вашего ПК.

* **Выбор адаптера** — отображает список всех сетевых интерфейсов Windows (**Ethernet, Wi-Fi / Беспроводная сеть, виртуальные адаптеры**). Список определяется мгновенно через WinAPI с резервным опросом через PowerShell.
* **«Обновить»** — повторное сканирование сетевых карт системы.
* **Чекбокс «Также IPv6»** — параллельная установка IPv6 DNS-адресов (если они поддерживаются провайдером).
* **Дерево провайдеров** — структурированный список серверов по категориям (*Популярные, Безопасные, Для ИИ (SmartDNS), Свои DNS*).
* **Поле «Текущие DNS адаптера»** — в реальном времени показывает, какие DNS сейчас установлены на выбранной сетевой карте (статические или автоматические DHCP).
* **Кнопка «+ Свой DNS»** — позволяет зарегистрировать собственный DNS-сервер:
  * Поддерживаются классические DNS с IPv4/IPv6.
  * **Поддерживаются DoH-серверы без статических IP** (только HTTPS-ссылка `https://.../dns-query`). Такие серверы сразу подключаются к тестированию ИИ и автозаполнению каталога.
* **Кнопка «⚡ Проверить работу с ИИ»** — запуск мощного встроенного бенчмарка DoH-серверов.
* **Кнопка «Очистить кэш»** — ручной сброс DNS-кэша Windows (`flushdns`).
* **Кнопка «Сбросить на авто»** — возвращает сетевую карту к стандартному автоматическому получению DNS от роутера/провайдера (DHCP).
* **Кнопка «Применить DNS»** — прописывает выбранный из дерева DNS-сервер в настройки сетевой карты Windows.

---

### ⚡ Диалог «Тестирование DoH-серверов для ИИ»
Инструмент для проверки работоспособности DNS-прокси перед их использованием.

* **Что проверяется**:
  * **ChatGPT** (`https://chatgpt.com`) — детект кодов 200/302 vs геоблок 403 / Cloudflare Block.
  * **Claude AI** (`https://claude.ai`) — проверка доступности и обхода регионального запрета Anthropic.
  * **Google AI Studio** (`https://aistudio.google.com`) — отслеживание редиректов на страницу недоступных регионов (`available_regions`).
* **Чекбокс «Показывать только работающие с ИИ»** — мгновенно скрывает заблокированные серверы, оставляя только зеленые рабочие шлюзы.
* **Кнопка «Проверить все» / «Остановить»** — последовательное тестирование всех серверов с индикатором прогресса и замером пинга (мс). Проверку можно остановить в любой момент.
* **Кнопка «Проверить выбранный»** — быстрый тест только одной выделенной строки таблицы (не нужно ждать завершения всего списка).

### 3. Вкладка «Каталог»
Управление внутренней базой сервисов, доменов и их IP-адресов.

* **Верхняя панель действий**:
  * **«+ Сервис»** — добавление нового сервиса в каталог.
  * **«Редактировать»** — открытие редактора доменов и вариантов DNS.
  * **«Удалить»** — удаление сервиса (встроенные защищены, пользовательские удаляются свободно).
  * **Меню «Каталог ▾»**:
    * *Сохранить изменения (catalog.json)* — ручная фиксация каталога на диск.
    * *Импорт из JSON…* — загрузка стороннего каталога.
    * *Экспорт в JSON…* — сохранение резервной копии базы.
    * *Импорт из папки (формат zapret)* — миграция из раздельных файлов оригинального zapret.
* **Блок «⚡ Обновление обходных IP для нейросетей (SmartDNS)» (Основное)**:
  * Кнопка **«⚡ Обновить IP через SmartDNS»** запускает автоматический модуль `catalog_updater`. Скрипт опрашивает SmartDNS-шлюзы (*DNS-AI, Comss, GeoHide, Mafioznik, Xbox DNS, Shecan и др.*) через RFC 8484 wireformat, отбирает только реально работающие серверы и прописывает актуальные IP-шлюзы для всех доменов ИИ в базу `catalog.json`.
* **Блок «Дополнительно: прямое разрешение через публичный DoH»**:
  * Разрешает домены в обычные прямые IP-адреса через публичные резолверы (*Cloudflare, Google, Quad9, AdGuard*). Предназначено для сайтов, блокируемых провайдером только на уровне подмены DNS-ответа.

## 🚀 Установка и запуск из исходников

### Требования
* Windows 10 / 11 (64-bit)
* Python 3.9 или выше

```cmd
git clone https://github.com/your-repo/hosts-dns-manager.git
cd hosts-dns-manager
python -m pip install -r requirements.txt
python main.py
```
*При запуске программа автоматически запросит повышение прав UAC (права Администратора необходимы для изменения `hosts` и смены DNS на сетевых адаптерах).*

---

## 🔨 Сборка единого EXE-файла

Сборка осуществляется через автоматический скрипт **`build_exe.bat`**:

```cmd
build.bat
```

Или вручную через PyInstaller:
```cmd
python -m pip install pyinstaller
python -m PyInstaller --noconfirm --clean --windowed --onefile --uac-admin ^
  --name HostsDnsManager ^
  --add-data "data;data" ^
  main.py
```

### 🔒 Сохранение данных в однофайловом режиме (`--onefile`)
Приложение учитывает особенности работы PyInstaller:
* Готовый файл `dist\HostsDnsManager.exe` не теряет настройки при перезапуске.
* Пользовательская папка `data/` (`catalog.json`, `settings.json`) сохраняется **непосредственно рядом с `.exe` файлом**.
* При первом запуске дефолтный каталог безопасно извлекается из exe-контейнера в папку `data/`, и в дальнейшем любые добавленные вами сайты, созданные категории, пользовательские DNS и выбранные флажки сохраняются на постоянной основе.

## 📂 Структура проекта

```
HostsDnsManager/
├── main.py                     # Точка входа в программу
├── build.bat                   # Автоматический скрипт сборки автономного EXE
├── requirements.txt            # Зависимости (PyQt5)
├── README.md                   # Руководство пользователя и документация
├── data/
│   ├── catalog.json            # База сервисов, доменов и IP-адресов
│   ├── settings.json           # Пользовательские настройки (сохраненные выборы, свои DNS)
│   └── icon.ico                # Иконка приложения
└── app/
    ├── admin.py                # Проверка и запрос прав Администратора (Windows UAC)
    ├── catalog.py              # Модель каталога сервисов и путей хранения
    ├── catalog_updater.py      # Модуль фонового обновления SmartDNS для ИИ
    ├── dns_manager.py          # Управление сетевыми адаптерами (WinAPI / netsh / PowerShell)
    ├── dns_tester.py           # Детектор доступности ChatGPT, Claude, Google AI через DoH
    ├── hosts_manager.py        # Безопасное чтение/запись блока hosts, создание бэкапов
    ├── providers.py            # Каталог встроенных и пользовательских DNS-провайдеров
    ├── resolver.py             # Прямой резолвер доменов через публичные DoH
    └── gui/
        ├── add_dns_dialog.py       # Диалог добавления своего DNS / DoH
        ├── add_service_dialog.py   # Диалог добавления сайта со списком доменов и группой
        ├── catalog_tab.py          # Вкладка управления каталогом и DoH-резолвингом
        ├── dns_tab.py              # Вкладка настройки DNS адаптеров
        ├── dns_test_dialog.py      # Диалоговое окно бенчмарка и тестирования ИИ
        ├── hosts_tab.py            # Главная вкладка включения сайтов в hosts
        ├── main_window.py          # Главное окно с вкладками
        └── theme.py                # Темная и светлая темы оформления (Fusion)
```
